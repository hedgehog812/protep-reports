# PROTEP Reports App

Минимальный прототип веб-приложения для ВКР: формирование Excel-отчётов по объектам недвижимости АО «ПРОТЭП» с сохранением данных в облачной БД и загрузкой отчётов в облачное хранилище.

## Что умеет прототип

К основным возможностям системы можно отнести добавление объектов недвижимости, хранение сведений в облачной базе данных Supabase, формирование отчёта в формате Excel, загрузку отчёта в Supabase Storage и просмотр ранее созданных отчётов по ссылке из облака.

## Стек

- Python
- Flask
- Supabase Database
- Supabase Storage
- openpyxl

## Установка

```bash
pip install -r requirements.txt
```

## Настройка Supabase

1. Создайте проект на https://supabase.com
2. Выполните SQL из файла `supabase_schema.sql`
3. Создайте bucket в Storage с названием:

```text
reports
```

4. Скопируйте файл `.env.example` в `.env`
5. Заполните переменные:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_anon_or_service_key
SUPABASE_BUCKET=reports
```

## Запуск

```bash
python app.py
```

После запуска откройте:

```text
http://127.0.0.1:5000
```

## Демонстрационный сценарий для защиты

Пользователь добавляет объект недвижимости в веб-приложение. Система сохраняет данные об объекте в облачной базе данных. После нажатия кнопки «Сформировать отчёт» приложение создаёт Excel-файл со списком объектов, загружает его в облачное хранилище и сохраняет ссылку на файл в базе данных. Далее пользователь открывает созданный отчёт из списка ранее сформированных отчётов.
